# Мінімальний елемент побічної діагоналі матриці з файлу

## Опис задачі

Модифікація програми опрацювання двовимірного масиву: замість введення
матриці 5×5 з клавіатури, дані зчитуються з текстового файлу `matrix.txt`.
Програма знаходить мінімальний елемент побічної (другорядної) діагоналі —
тобто елементи `a[i][N-1-i]` для `i = 0..4`.

## Алгоритм розв'язання

1. Відкрити файл `matrix.txt` для читання.
2. Зчитати 25 цілих чисел у масив `matrix[5][5]` по рядках.
3. Вивести матрицю на екран для візуальної перевірки.
4. Ініціалізувати мінімум значенням `INT32_MAX`.
5. Пройти по індексах `i = 0..4`, на кожному кроці звертаючись до
   елемента `matrix[i][N-1-i]`.
6. Оновлювати мінімум через `min()`.
7. Вивести знайдене мінімальне значення.

## Основні етапи роботи програми

| Етап | Що відбувається |
|------|-----------------|
| Відкриття файлу | `ifstream file("matrix.txt")`. Якщо файл не знайдено — програма виводить помилку і завершується з кодом `1`. |
| Зчитування матриці | Подвійний цикл `for` по `i` та `j` заповнює масив через `file >> matrix[i][j]`. Числа у файлі можуть бути розділені пробілами або переносами рядків. |
| Виведення матриці | Матриця виводиться на екран з вирівнюванням через `\t` — для перевірки коректності зчитування. |
| Пошук мінімуму | Цикл по `i = 0..4` звертається лише до елементів побічної діагоналі `matrix[i][N-1-i]`. |
| Виведення результату | На екран виводиться мінімальний елемент побічної діагоналі. |

> Файл `matrix.txt` має знаходитись у тій самій папці, що й виконуваний файл.

## Приклад `matrix.txt`

```
3  7  1  9  4
2  8  6  5  0
1  3  2  4  7
6  9  8  1  3
5  2  7  4  8
```

## Приклад роботи

```
Матриця:
3       7       1       9       4
2       8       6       5       0
1       3       2       4       7
6       9       8       1       3
5       2       7       4       8
Мінімальний елемент побічної діагоналі: 2
```

Побічна діагональ: `4, 5, 2, 9, 5` → мінімум `2`.
