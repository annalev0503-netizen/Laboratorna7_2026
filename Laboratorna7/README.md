# Добуток від'ємних чисел з файлу

## Опис задачі

Консольний застосунок на C++ зчитує 10 цілих чисел з текстового файлу
`number.txt` та обчислює добуток лише від'ємних чисел.
Якщо від'ємних чисел у файлі немає — виводить відповідне повідомлення.

## Алгоритм розв'язання

1. Відкрити файл `number.txt` для читання.
2. Зчитувати числа по одному в циклі.
3. Для кожного числа перевірити: якщо `number < 0` — множити на поточний добуток.
4. Після завершення читання перевірити прапорець `hasNegative`.
5. Якщо від'ємні числа були — вивести добуток, інакше — повідомлення про їх відсутність.

## Основні етапи роботи програми

| Етап | Що відбувається |
|------|-----------------|
| Відкриття файлу | `ifstream file("number.txt")`. Якщо файл не знайдено — програма виводить помилку і завершується з кодом `1`. |
| Читання чисел | Числа зчитуються через `file >> number` у циклі `while` до кінця файлу. |
| Фільтрація | Перевіряється умова `number < 0`; лише від'ємні числа беруть участь у множенні. |
| Накопичення добутку | Змінна `product` типу `long long` множиться на кожне від'ємне число. `long long` обраний для уникнення переповнення. |
| Виведення | Якщо прапорець `hasNegative` встановлено — виводиться добуток, інакше — повідомлення `"Від'ємних чисел немає"`. |

> Файл `number.txt` має знаходитись у тій самій папці, що й виконуваний файл.

## Приклад `number.txt`

```
5 -3 8 -2 0 -7 4 1 -1 6
```

## Приклад роботи

```
Добуток від'ємних чисел: -42
```

Від'ємні числа: `-3`, `-2`, `-7`, `-1` → добуток: `(-3) × (-2) × (-7) × (-1) = -42`.

## Примітка

Прапорець `hasNegative` необхідний: без нього за відсутності від'ємних чисел
програма вивела б `1` — нейтральний елемент множення, що є математично
коректним, але семантично оманливим результатом.
